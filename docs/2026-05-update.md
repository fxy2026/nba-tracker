# 2026-05 Update — The Perfection Push

A ~50-commit optimization pass turning NBA Tracker from "feature-rich rough draft" into a production-grade modern web app. Spanning 100+ files and ~21,000 new lines of code.

Started by a single timezone bug (China user saw NBA's ET "today" instead of their actual today) and snowballed into a full-stack quality push.

## What's intentionally NOT done

- **Service Worker for /api/***: live scoreboards must always hit network
- **View Transitions API**: perf cost > visual gain in current evaluation; revisit after stable RC
- **`hreflang`**: requires separate URLs per language; current cookie-based switch is incompatible
- **Real-time WebSocket scoreboard**: 30s polling is sufficient for the use case
- **Push notifications**: requires backend infrastructure not in Vercel free tier
- **Big page splits**: rest of pages under 500 LOC, not worth the churn
