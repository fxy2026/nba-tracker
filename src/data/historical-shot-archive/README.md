# Historical shot-summary archive

This snapshot contains all 60 allowlisted regular-season/playoff packs for 1996-97 through 2025-26: 6,328,070 accepted shot rows, 2,840 distinct player IDs, and 20,421 player-season/type entries. The 18 newly imported packs contain 1,756,750 raw rows; one 1996-97 Eric Montross row has no explicit SHOT_TYPE and is quarantined, leaving 1,756,749 accepted rows. Its original record is retained in early-import-validation-report.json, excluded consistently from player/league totals and both spatial resolutions, and disclosed in the selected season’s coverage. No point value is guessed. Missing seasons are never exposed as zero-attempt seasons.

Compressed summaries stay on the server. The player-season API returns one bounded renderer DTO per selection; directory searches return at most 48 players. The gzip catalog and source summaries are not public assets or client imports.

Source: `fxy2026/nba_data`, revision `e829d4678be1e075f99e5d41a1c5f97089be446b`, NBA shotdetail regular-season/playoff files only. `catalog-index.json` records exactly the bundled files and SHA-256 hashes. A catalog entry means source data exists, not that the season is independently complete. No absent player-season is filled with zeros.

The default court-aligned 12-zone view is recomputed from exact source BASIC/AREA/RANGE groups: restricted area, non-restricted paint, five midrange directions, two corners and three above-break directions. Contradictory explicit point-type counts remain in a non-spatial classification-conflict residual. The legacy 14 distance/direction summaries remain retained in source, not reused as court-zone counts. Residual categories stay non-spatial and remain in the denominator. Three-point totals always use explicit source SHOT_TYPE, including historical shorter-line seasons and contradictory distance classifications. League comparisons are weighted counts from that same archive and season type; they are not NBA-displayed LA. Original source download dates and later metadata observation dates remain distinct. The 18 early packs were read from a user-authorized local Git clone; their timestamp is explicitly a minute-precision local blob verification time, not an invented HTTP download date.

Official verified Curry 2025-26 and 2015-16 distance-zone aggregates are preserved unchanged as separate source facts. The new default court-aligned 2015 view uses the raw archive (804/1596 FG, 401/884 3P), explicitly compared with official controls (805/1598 FG, 402/886 3P); the shortfall is never assigned to a fabricated court region. Optional official controls verify only aggregate shooting totals, not every event or league coverage. Games containing shots are never relabelled as games played; official GP is displayed only with its separately sourced control.

Runtime checks compressed digests, bounds decompression, validates identity/counts/dates, retains two decompressed summaries and up to 256 immutable player DTOs. Failed reads and corrupt data are errors, not cached fabricated records. Next file tracing includes compressed data only for consuming server routes.

`staging-release-manifest.json` retains the source export manifest unchanged. Its original per-pack `*-manifest.json` paths are stored under `manifests/` here; the original summary bytes remain identical; the current catalog is extended by the later local import. `semantic-content-digests.json` records count/classification identities separately from audit timestamps. Original parser versions remain explicit.

The original 42 summaries and 42 spatial assets remain byte-identical. The immutable original partial staging and tooling manifests describe that earlier release only. `early-import-source-manifest.json`, `early-import-validation-report.json`, and `early-import-release-manifest.json` describe the added local import and the current 60-pack catalog. The local-only importer is `scripts/historical-shots/import_early_archives.py` (v1.2.0), uses Python standard-library CSV parsing, verifies pinned Git blobs, bounds XZ expansion/memory, accepts one exact regular CSV tar member, and neither extracts archives nor runs upstream code. All four count fields, both grids, and player/league sums are conserved. All six Michael Jordan datasets total 7,660 attempts; secondary career aggregate crosschecks do not make them official NBA controls. Coverage begins in 1996 and does not establish complete NBA or player-career history.
